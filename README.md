## 它解决什么

详情页和店内推荐卡最常见的样子是：一张圆角卡片，中间放商品照片，下面三行字。信息都有，但谁也记不住。

**Shop 003** 不从卡片模板出发。牌子的外形由**商品的轮廓、名字的字形和几块信息**一起决定：商品可以从边缘探出来，名字可以绕着商品转，价格可以是一枚小签，口味可以是一条丝带。最后是一整块图形，而不是几样东西贴在底板上。

远看先认出商品和名字，再看到价格或卖点，凑近才发现口味、规格和小趣味。

## 你需要准备

- **商品名称：** 必需，名字本身就是轮廓的一部分。
- **商品图：** 推荐，抠图、越界、穿插都靠它。
- **价格、规格、口味、原料：** 用 `--facts` 写明。没给价格，牌子上就没有价格签，也不会出现“¥XX”这种占位符。

## 快速判断

| 你关心的问题 | 回答 |
|---|---|
| **你会得到什么** | 一枚放在干净底色上、可以直接贴进详情页或做成物料的商品推荐牌 |
| **一眼可辨的特点** | 异形外轮廓 · 商品咬进牌面 · 有性格的商品名 · 信息块长在结构里 · 少量趣味小图形 |
| **它不会做什么** | 不套圆角卡片、不编价格、不在牌面外加场景、不让贴纸满天飞 |

## 使用窍门

- **一枚牌只讲一件商品。** 买一送一、组合装可以把组合当成一件商品来命名。
- **事实给得越准，信息块越好看。** “250g / 原味 / 新西兰黄油”比一句“很好吃”更能长出结构。
- **要透明底就说。** 成品先在单色底上生成，再抠图交付，不会画假的棋盘格。
- **一套 SKU 一起做：** 给一个商品图目录，每件商品一枚牌，轮廓各不相同。

## 开始使用

```bash
git clone https://github.com/nevertoday/xxd-shop-003.git
ln -s "$(pwd)/xxd-shop-003" ~/.claude/skills/xxd-shop-003
```

```text
# 商品图 + 价格规格，文字由模型按原稿组织
/xxd-shop-003 ./海盐芝士贝果.png --product "海盐芝士贝果" --facts "¥16；单个 120g" --size 1:1 --text prompt --locale zh-CN

# 你有一整段卖点文案，让它按牌面层级理顺
/xxd-shop-003 ./冻干草莓.png --product "冻干草莓脆" --text plan --copy "整颗冻干 不加糖 酸甜脆口 一袋 30g 办公室零食" --locale zh-CN

# 一套 SKU，每件一枚推荐牌
/xxd-shop-003 ~/Desktop/新品SKU/ --size 4:5 --text prompt --locale zh-CN
```

常用参数：`--product` · `--facts` · `--text prompt / exact / plan / none` · `--copy` · `--size` · `--count` · `--locale`。完整参数见[家族运行合同](references/shop-runtime.md)。

## 边界与信任

- 原始提示词逐字保存，是唯一的审美权威。
- “爆浆、现烤、低甜”这类描述商品属性的词，只在看得出来或你说过时出现；“人气款、新品、限定”需要你确认。
- 交付 PNG 位图；每次调用都新建任务目录。
