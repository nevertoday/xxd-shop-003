# Original XXD Shop 003 style brief

为当前商品设计一枚具有强识别度的电商异形标签牌 / 产品推荐牌。

若用户提供产品图，以真实商品为核心，准确保留商品造型、颜色、包装、材质和关键识别特征；若仅提供产品名称或品类，则根据商品属性、口味、卖点、品牌气质和消费场景建立对应视觉。

不要套用固定圆形、方形或常规卡片模板。异形外轮廓应从“商品形态 + 产品名称字形 + 信息块 + 装饰元素”之间自然生长出来，让整块标签像一个完整图形，而不是把若干元素贴在底板上。轮廓可以产生伸出、包裹、转折、错位、局部突出、贴纸描边或层叠关系，但整体必须紧凑、完整、方便一眼识别。

商品本身是视觉锚点，可采用抠图、局部突破边界、前后穿插、放大局部等方式融入牌面，使产品与标签结构真正咬合，而不是简单把商品照片摆在中间。

产品名称必须成为最有个性的视觉元素。根据商品气质智能选择手写、招牌字、圆润粗体、复古字、趣味变形字、笔触字、甜品感字体、潮流字形或其他适合的表现，让文字本身具有图形性。允许字形轻微旋转、错落、拉伸、重叠、描边、阴影或与产品轮廓穿插，但必须始终清晰易读，缩小后仍能迅速识别产品名。

必要商品信息不要机械排版，而要巧妙融入标签结构。价格、规格、口味、核心卖点、主原料、推荐语、品牌名、英文名、促销信息等，可以根据重要程度自然形成价格签、推荐章、小贴纸、角标、丝带、手写便签、圆章、弧形文字、迷你信息框或边缘注释。每一块信息都应像设计的一部分，而不是后加的说明文字。

可根据产品特性智能生成少量贴纸语言，例如“招牌推荐、店长推荐、人气款、经典口味、新品、限定、手作、真材实料、浓郁、低甜、爆浆、现烤、必点”等；不要固定照搬，应该判断这个商品最值得强调的购买理由，再生成最合适的标签内容和视觉形式。

颜色从商品本身延展，产品主色、口味色、品牌色和辅助色彼此呼应。允许明快、复古、甜美、浓郁、清爽或潮流，但避免无依据的杂色堆砌。外轮廓、描边、底色和局部信息块应帮助商品从电商页面中跳出来。

可以自然加入与产品相关的小型插画、原料图形、手绘线条、符号、星星、叶片、果实、餐具、味觉符号、英文弧字或轻微装饰，让信息更有趣，但数量克制，不让装饰压过产品。

最终效果应像成熟品牌专门为这个商品设计的一枚“可独立成立的视觉徽章”：
远看先看到产品名和商品，
再看到价格或核心卖点，
近看才发现口味、规格、原料和趣味细节。

整体要求：异形轮廓有创意、商品突出、名字醒目、信息完整但不拥挤、字体有性格、层级清晰、具有强电商点击感和品牌记忆点。

避免：套模板式圆角卡片、商品与底板割裂、所有信息都放矩形框、字体普通、价格孤立、贴纸满天飞、元素平均分布、轮廓没有特点、信息过碎、产品名不清楚。
