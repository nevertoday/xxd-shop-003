# 🦁 XXD Shop 003｜変形おすすめプレート

### 商品から生まれた、ひとつのビジュアルバッジ

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <strong>日本語</strong> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

</div>

**商品から生まれる変形のおすすめバッジを。ありがちな角丸カードではありません。**
輪郭は商品のシルエット、商品名の文字、いくつかの情報ブロックから決まるので、遠くからでも商品と名前がわかります。

| ひと目で分かる | |
|---|---|
| **渡すもの** | 商品名（必須）と商品画像（推奨）。価格、サイズ、味などの事実 |
| **受け取るもの** | 無地背景のバッジ。詳細ページや店頭印刷にそのまま使え、希望すれば透過版も |
| **スタイルの特徴** | 変形のシルエット · 商品とプレートの噛み合い · 個性のある商品名 · 構造に組み込まれた情報 · 遊び心のある小さなマーク |
| **向いている用途** | 詳細ページのおすすめモジュール、店頭カード、プライスカード、新作コーナー |

> **インストールしたら、こう言うだけ：**
>
> /xxd-shop-003 塩チーズベーグル、1個 ¥16、120g。おすすめバッジを作って

## 解決すること

詳細ページや棚のカードはどれも似ています。角丸カード、中央に商品写真、3行の文字。情報はそろっているのに、誰の記憶にも残りません。

**Shop 003** はカードのテンプレートから始めません。バッジの輪郭は**商品のシルエット、商品名の文字、いくつかの情報ブロック**で決まります。商品が縁から身を乗り出し、商品名がそれを包み込み、価格は小さなタグに、味はリボンに。プレートに物を貼り付けたのではなく、ひとつの形になります。

遠くからは商品と名前、次に価格や一番のメリット。近づくと味やサイズ、細かなディテールが見つかります。

## 用意するもの

- **商品名**（必須）：名前は輪郭の一部になります。
- **商品画像**（推奨）：切り抜き、縁を破る表現、噛み合わせはすべて写真が頼りです。
- **価格・サイズ・味・原材料**（推奨）：正確なほど情報ブロックが良くなります。価格がなければプライスタグも「¥XX」の仮置きも出しません。
- **自分のセールスコピー**（任意）：渡せばそれを使い、なければ先に下書きを作ってあなたの確認を待ちます。

## 使い方

### ステップ 1：インストール（1回だけ）

```bash
git clone https://github.com/nevertoday/xxd-shop-003.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-003" ~/.claude/skills/xxd-shop-003
```

Codex を使う場合は、同じフォルダを `~/.codex/skills/xxd-shop-003` にリンクしてください。インストール後は AI アシスタントのセッションを再起動します。

### ステップ 2：やりたいことを普通の言葉で言う

```text
/xxd-shop-003 塩チーズベーグル、1個 ¥16、120g。おすすめバッジを作って
/xxd-shop-003 フリーズドライいちごチップス：まるごと苺、砂糖不使用、甘酸っぱいサクサク食感、30g 袋
/xxd-shop-003 ~/Desktop/new-skus の商品それぞれに 4:5 のバッジを1枚ずつ
```

覚えるフラグはありません。サイズや枚数など決めていないことは一度にまとめて質問され、次回は前回の設定を再利用できます。

### ステップ 3：そのあと何をするか

1. 商品画像と説明を読み、まだ決まっていないことだけを質問します。サイズは用途から、ピクセル数付きで提案します。
2. コピーがないときは、まずバッジの文言を下書きし、各行に出どころ（あなたの説明、パッケージ、あなたの事実）を記します。確認か修正のあとで生成します。
3. サイズごとに構図を新しく作り、別の画像から切り抜くことはありません。
4. 納品前に1枚ずつ確認します。商品は変わっていないか、文字のつづりは正しいか、渡していない数字はないか。通らないものは報告して作り直します。
5. PNG を `~/Desktop/xxd/xxd-shop-003/` の下の新しいタスクフォルダに保存し、パスを伝えます。

## よくある質問

**透過背景にできますか？**

言ってくれれば大丈夫です。無地の背景で生成してから切り抜きます。グレーと白の市松模様を描くことはありません。

**「店長のおすすめ」「売れ筋」を勝手に付けますか？**

いいえ。お客さんはそれを本物の推薦として読むので、あなたが言ったときだけ載せます。「とろける」「焼きたて」のような形容も、見て分かるときかあなたが言ったときだけです。

**何が必要ですか？**

3つです。① Claude Code や Codex など、Skills に対応した AI アシスタント。② 画像を生成できるモデル。アシスタント内蔵の画像生成、または Codex に設定したモデルプロバイダーで Responses API 経由で画像を生成するもの（既定は GPT Image 2）。③ Pillow 入りの Python 3.11 以上（`pip install pillow`）。

**お金はかかりますか？商用利用できますか？**

Skill は無料でダウンロードできます。画像生成の費用はあなた自身のモデルアカウントに請求されます。本プロジェクトは PolyForm Noncommercial ライセンスです。個人の学習・研究・テストには使えますが、ショップ運営、受託制作などの商用利用には事前に作者の書面による許可が必要です。末尾の「ライセンス」を参照してください。

**画像の大きさは？**

比率か正確なピクセル数を指定できます。実際のサイズはモデルが返したとおりで、こっそり拡大することはなく、ファイル名に本当のピクセル数が書かれます。

**画像内の文字に誤字は出ますか？**

AI の画像では、ときどき文字を間違えたり、ブランド名の横に ® のような小さな記号を足したりします。納品前に1枚ずつ拡大して確認し、通らないものは作り直します。このページの作例はすべてその確認を通っています。

**価格や販売数をでっち上げませんか？**

しません。価格、仕様、産地、販売数、受賞、認証など事実に見えるものは、あなたが提供したものか、商品にはっきり読める文字からだけ取ります。それ以外は載せず、「¥XX」の仮置きもしません。

**たくさんの商品を一度に処理できますか？**

できます。商品画像のフォルダを渡してください。1枚の画像に商品1つ、サイズと文字は一度だけ質問され、ある商品の事実やコピーが別の商品に混ざることはありません。

## 原則

- **スタイルは忠実に：** この Skill の背後には成熟した商業デザインのプロンプトがあります（[原文プロンプト](references/original-prompt/zh-CN.md) · [英語の参考訳](references/original-prompt/en.md)）。Skill はそれを書き換えたり、独自の色やアートディレクションを足したりせず、あなたの商品、サイズ、文字、事実をモデルに渡すだけです。
- **商品をデザインし直さない：** 商品画像があれば、形、色、パッケージの文字、ロゴは写真どおりです。
- **あなたの事実だけ、** そして商品はそれぞれ独立。ほかの商品、以前の結果、作例から何も借りません。
- **本物の PNG ビットマップ。** SVG やコードで描いた絵を画像として出すことはなく、実行のたびに新しいタスクフォルダを作ります。
- バッジ1枚に商品1つ。セット商品は名前を付けて1つの商品として扱えます。

## Xiaoxiaodong マルチプラットフォーム会員 · 年額 CNY 699

> **広告表示：** 以下のQRコード、会員および有料サービスのリンクはXXDの広告情報です。スキャンや購入は任意であり、オープンソースの利用には影響しません。

年額会員ひとつで、**Knowledge Planet＋XXD会員プロンプトライブラリ＋すべてのGeneral Skills会員**の3つを利用できます。別々に購入する必要はありません。

### Skills の連携方法

| 区分 | 含まれるもの | 役割 |
|---|---|---|
| **General** | `xxd-shop-all` | 利用可能な番号付きSkillsを検出し、商品・掲載場所・ビジュアルの要件から推薦し、複数スタイルや一括タスクを整理します。 |
| **Soldier** | `xxd-shop-NNN` | 各番号が固有の原文プロンプトと美学に従い、Generalから割り当てられた具体的な作業を完成させます。 |

### 会員の内容

1. **WeChatでの一対一AI学習・プロジェクト相談**
   下のQRコードからXiaoxiaodongのWeChatを追加し、AI学習、ツール、実際のプロジェクトについて一対一で相談できます。代表的な質問は会員向けコンテンツに整理されます。
2. **継続更新する会員プロンプトライブラリ**
   [XXD会員プロンプトライブラリ](https://vip.xiaoxiaodong.ai/)には現在約3.2万件のプロンプトがあり、10万件超を目標に継続して拡充します。
3. **すべてのGeneral Skillsと利用サポート**
   ひとつの会員で全General Skillsを利用でき、使い方に困ったときは案内やQ&Aを受けられます。
4. **必要性の高い要望を優先**
   会員から寄せられた頻度と必要性の高いプロンプトやSkillsは、優先して検討・開発します。

### 開設方法

- [会員サイトから自分で開設](https://vip.xiaoxiaodong.ai/)できます。
- または下のQRコードからXiaoxiaodongのWeChatを追加し、一対一で開設サポートを受けられます。
